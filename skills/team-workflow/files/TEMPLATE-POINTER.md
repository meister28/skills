## Canonical template

This working agreement is instantiated from the canonical template at
`~/.agents/skills/team-workflow` (a user-level Agent Skill: `SKILL.md` plus
generalized template files under `files/`). If you change this agreement —
the rules, the queue conventions, or the folder contracts — back-port the
change to the skill's `files/` templates in the same session, so every
future project that runs the skill inherits it. The skill's Mode B
(adoption) diffs existing files and never overwrites without per-file
owner confirmation.
