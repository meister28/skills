# team/specs/ — specifications and design documents

Implementation-ready specs live here, named `P-NNN-<NAME>-SPEC.md` for the
backlog item they specify (e.g. `P-007-SEARCH-SPEC.md` for the P-007 task). A task with a
spec references it from its `team/TASKS.md` record by path.

What belongs here: a spec written **before** implementation that another
agent could implement from cold — exact selectors/commands where they
matter, acceptance criteria per section, and an explicit out-of-scope or
not-touched list. Design briefs and design reports that back a spec live
beside it.

This folder is the documentation and communication channel between agents:
write the spec here, do not paste its content into chat as a substitute,
and keep it truthful in the same commit as the change it describes
(AGENTS.md rule 2).
